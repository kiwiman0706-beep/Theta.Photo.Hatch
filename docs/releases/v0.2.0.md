Theta Hatch シリーズに参加した最初の版です。**アプリ ID が変わったので、0.1.0（Photo Hatch）をアンインストールしてから入れてください**（仕分け済みの写真と XMP は端末に残ります）。

## シリーズ
- アプリ ID `app.thetahatch.photo`、表示名「Theta Photo Hatch」、シリーズ共通の鍵で署名
- 更新は Theta Home Hatch・KidsHome Hatch（ハブ）に頼む（無ければ Releases ページを開く）。設定に「今の版」「更新を確認」
- スキン（ui.skin、11 種）。ハブのスキンに合わせられる
- NAS の接続先はハブから。パスワード・2 段階認証のデバイストークンは「Home Hatch の設定を使う」で受け取れる
- 設定の書き出し・読み込み（Documents/ThetaPhotoHatch/）

## 新しいこと
- **USB から取り込む**（未処理の右上の USB）：デジカメ・GoPro・THETA（MTP／PTP）、カードリーダー・USB メモリ。`Pictures/Hatch_Inbox/<機器>/` へコピーして未処理に出す。元は消さない、取り込み済みは飛ばす
- **NAS へ上げる**（仕分け済み → NAS へ上げる）：File Station へ直接、`<アップ先>/<年>/<YYYY-MM-DD> <イベント>/`。Wi-Fi のときだけ（設定で変えられる）。上げたら NAS の大きさを確かめる。2 段階認証（Secure SignIn）対応。端末からは消さない
- **Theta Camera Hatch と連携**：`DCIM/ThetaCamera/` も未処理に出す。撮影時のイベント・☆・タグ・コメントを引き継ぎ、`.theta.json` も写真の隣へ。移すか、Camera に残してコピーかを設定で選べる
- **ビューア**（長押し・ほかのアプリから「開く」）：HEIF の clap（表示範囲）どおりに切って表示（「全体」で切らずに）。THETA などの **360° 写真**をぐるっと見回す（端末の向きでも）
